# Ablative wall boundary conditions (BC 503 / 504)

Verification case for the gas-surface interaction wall boundary conditions,
against an analytic solution. No solver-level case exercised these boundary
conditions before.

## Setup

A thin gas column, one-dimensional in `y`:

```
   face 4 (j = ny)   outflow (extrapolation)
 +---------------------+
 |                     |
 |     gas column      |   faces 1, 2 : symmetry  -> the solution is 1-D
 |                     |
 +---------------------+
   face 3 (j = 1)    ablating wall, BC 503 or 504
```

The wall blows gas into the column; it vents at the top. The column is
initialised isothermal at the wall temperature and at rest, so the velocity
field has to be generated by the blowing itself.

## Why it has an analytic solution

With the column isothermal the conductive flux at the wall vanishes, and the
surface energy balance collapses to a single scalar equation:

* **melting (503)** — the wall temperature is prescribed, so the mass flux
  follows directly,
  `mdot = qrad / (dh + cp (Tw - Ti))`;
* **pyrolysis (504)** — the mass flux obeys an Arrhenius law in `Tw`, and `Tw`
  is the root of `q_pyro(Tw) = qrad`, found by bisection in `verify.py`.

With `p` and `T` uniform the density is uniform too, so continuity fixes the
blowing velocity at `v = mdot / rho` everywhere in the column. The isothermal
blown column is thus an exact steady solution, and the test checks that the
solver both reproduces it and reports the right wall quantities.

`verify.py` also checks the algebraic identities of the wall models themselves
(`mdot * heat_absorbed = q_wall`, `mdot = Arrhenius(Tw)`), which hold for
whatever state the solver reached and so test the boundary condition rather
than the convergence. Those hold to round-off.

## Running

```sh
./run.sh                      # all four configurations, as CTest runs it
CONFIGS=hdpe ./run.sh         # just one

python3 build_case.py hdpe    # generate mesh / IC / BC by hand
./MOSE.sh solve
python3 verify.py
```

## Configurations

| name | BC | what it covers |
|---|---|---|
| `melting` | 503 | prescribed wall temperature, radiatively driven |
| `htpb`, `hdpe`, `pp` | 504 | the three pyrolysis models |
| `melting-top`, `hdpe-top` | 503 / 504 | the same walls on the opposite face, which exercises the other branch of the face-orientation bookkeeping |
| `melting-inert` | 503 | a surface that *cannot* ablate: no radiation and a gas colder than the wall, so the melting energy balance returns a non-positive mass flux and the boundary condition has to fall back to an impermeable isothermal wall |

## Why the whole column is checked, wall cell included

An ablating face carries its complete flux — wall pressure, the momentum and
enthalpy convected in with the blown mass, and the viscous terms — and no
reflective wall flux is applied alongside it. A reflective (symmetry) treatment
imposes `u.n = 0` at a face that is deliberately permeable and returns the
impermeable-wall pressure, which overshoots the true wall pressure by roughly
`rho*c*u_blow`: negligible against `p`, but comparable to the pressure
differences that drive a low-speed blown boundary layer. With it in place the
wall-adjacent cell carried a mesh-independent ~36 % mass-flux deficit; the
continuity check covers every cell precisely because that is now gone.
