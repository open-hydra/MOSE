# 1D Euler Problems

One-dimensional inviscid flow problems solved with the compressible Euler equations.  
Most cases are run on four successively refined meshes (×1, ×2, ×4, ×8) and verified against an exact analytical solution, with a maximum pointwise relative error below 1–1.5 % on the finest mesh, evaluated at selected probe locations away from discontinuities.  
The Shu–Osher problem has no closed-form solution and is instead checked against a well-resolved reference (see that section for its criterion).

## Sod Shock Tube

The classical shock-tube problem of Sod (1979).  
The initial left–right discontinuity generates a right-travelling shock, a contact discontinuity, and a left-travelling rarefaction fan.  
This is a standard benchmark for first- and second-order shock-capturing schemes.

**Reference**: G. A. Sod, _J. Comput. Phys._ **27** (1978) 1–31.

### Initial conditions

| Region | $\rho$ | $u$ | $p$ | $\gamma$ |
|---|---|---|---|---|
| Left ($x < 0.5$) | 1.0 | 0 | 1.0 | 1.4 |
| Right ($x \geq 0.5$) | 0.125 | 0 | 0.1 | 1.4 |

### Numerical setup

| Parameter | Value |
|---|---|
| Domain | $[0, 1]$ |
| Final time | $t = 0.2$ |
| Time scheme | RK3 |
| CFL | 0.9 |
| Space reconstruction | MUSCL |
| Flux limiter | MC |
| Riemann solver | SLAU |

## Einfeldt Double Rarefaction

The "123 problem" of Einfeldt et al. (1991): two streams moving apart generate two expanding rarefaction fans separated by a nearly vacuum region.  
The near-vacuum state stresses the positivity of density and pressure, making it a challenging test for numerical Riemann solvers.

**Reference**: B. Einfeldt et al., _J. Comput. Phys._ **92** (1991) 273–295.

## Noh Implosion Problem

The Noh (1987) infinite-strength implosion: a gas moving inward at unit velocity is brought to rest by an outward-propagating shock. The problem has an exact solution with a very strong density jump.  
An equivalent configuration, adopted in this case, presents an initial configuration with two regions at opposite velocity and same thermodynamic state. 

**Reference**: W. F. Noh, _J. Comput. Phys._ **72** (1987) 78–120.

## Toro Test Case 3

Test problem 3 of Toro (1999): a modified Sod problem with a non-zero left velocity and a larger left–right pressure ratio.  
This configuration produces a right-moving shock, a contact, and a left-moving shock (no rarefaction), exercising the solver across a fully compound wave pattern.

**Reference**: E. F. Toro, _Riemann Solvers and Numerical Methods for Fluid Dynamics_, 2nd ed., Springer, 1999.

## Shu–Osher Shock Entropy-Wave Interaction

The Shu–Osher (1989) problem: a Mach-3 shock advances into a sinusoidally perturbed density field.  As the shock passes, it generates fine-scale acoustic and entropy waves downstream, producing a high-frequency structure superimposed on the post-shock flow.  Resolving that structure stresses the scheme's ability to capture a strong shock while preserving smooth extrema, making it a classic discriminator of numerical dissipation.

Unlike the cases above, this problem has no closed-form solution.  A grid-independent density field is therefore estimated by **Richardson extrapolation** and every grid is measured against it.  Four solutions with
refinement ratio $r = 2$ take part in the study — $N = 200,\,400,\,800,\,1600$ — all interpolated onto a common set of points in the active region ($-4.5 \le x \le 3.5$).  From the three finest grids the observed order of accuracy is

$$
p = \frac{\ln\!\left(\lVert f_{4h}-f_{2h}\rVert_1 \big/ \lVert f_{2h}-f_{h}\rVert_1\right)}{\ln r},
\qquad
f_{\text{ext}} = f_{h} + \frac{f_{h}-f_{2h}}{r^{p}-1},
$$

and $f_{\text{ext}}$ is the Richardson extrapolant ($h \to 0$) of the two finest
grids.  The normalised $L_1$ density error of each grid against $f_{\text{ext}}$
is:

| Grid | Cells $N$ | $L_1$ error vs $f_{\text{ext}}$ |
|---|---|---|
| ×1 | 200 | 3.55 % |
| ×2 | 400 | 2.83 % |
| ×4 | 800 | 1.46 % |
| ×8 | 1600 | 0.72 % |

The observed order is $p \approx 1.02$ and the fine-grid Grid-Convergence Index
(GCI, $F_s = 1.25$) is $0.88\,\%$.  First order is expected for an $L_1$ norm
dominated by the captured shock, where MUSCL reconstruction degrades to first
order.

**Reference**: C.-W. Shu and S. Osher, _J. Comput. Phys._ **83** (1989) 32–78.

### Initial conditions

| Region | $\rho$ | $u$ | $p$ | $\gamma$ |
|---|---|---|---|---|
| Post-shock ($x < -4$) | 3.857143 | 2.629369 | 10.33333 | 1.4 |
| Pre-shock ($x \geq -4$) | $1 + 0.2\,\sin(5x)$ | 0 | 1.0 | 1.4 |

### Numerical setup

| Parameter | Value |
|---|---|
| Domain | $[-5, 5]$ |
| Final time | $t = 1.8$ |
| Time scheme | RK3 |
| CFL | 0.5 |
| Space reconstruction | MUSCL |
| Flux limiter | Van Leer |
| Riemann solver | HLLC |
